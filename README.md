DCIT 323 - Lab 1

Introduction

This repository was created as part of the DCIT 323 laboratory assignment to demonstrate the basic use of Git and GitHub for version control.

Objectives

The objectives of this assignment are to:

* Create a repository on GitHub.
* Clone the repository to a local machine.
* Create and edit files.
* Add changes to the staging area.
* Commit changes using Git.
* Push committed changes back to GitHub.

Git Commands Used

git clone repository-url
cd DCIT-323-Lab-1
git status
git add .
git commit -m "Initial commit"
git push origin main

Description

This project demonstrates how Git can be used to track changes in files and how GitHub can be used to store and manage project repositories.
